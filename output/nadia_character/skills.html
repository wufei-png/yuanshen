把失衡
写成一种方法

01 / Core Read

先看懂衡标，再看见冰

颜色不是唯一编码。方向、符号、轮廓和纹理一起告诉玩家：现在是在向外，还是正在回中。

H / 状态轨道

五格状态，一次明确选择

普莎 / 轻端 ← 归衡 → 伊嘉 / 重端

−2轻端观测
−1向轻端
0归衡
+1向重端
+2重端观测
向外：反应选路

Stellar Swirl 让 H 向轻端移动，普莎先上浮；Stellar-Conduct 让 H 向重端移动，伊嘉先落点。

回中：玩家决定

战技再次施放或元素爆发可把非零 H 带回 0；相反路线也能逐格回中。

Design Rule

“普通玩家不必一直盯着五格 UI；熟悉机制的玩家，可以把一次失衡变成一次完整归衡。”

What the player reads
  • 上行弧线 = 轻端 / 普莎 / 牵引。
  • 下沉楔形 = 重端 / 伊嘉 / 压制。
  • 闭合圆环 = 归衡 / 零点 / 共同校准。
  • 符号 `− / 0 / +` 永远和颜色同时出现。
02 / Player Edition

技能不是更多按钮

每个技能只承担一个清晰动作职责：记录、巡衡、归零，或让玩家读出有限的状态收益。

NA / 普通攻击

霜度测录

操纵记录册与悬浮测量环，进行最多四段冰元素攻击。

基础动作，不额外改变衡标；四段差异来自书页、环的轴向与镜头节拍。
E / 元素战技

双相巡衡

打开记录册，让普莎与伊嘉进入巡衡；反应选择路线，归衡校读负责主动回中。

巡衡提供后台冰协同；反应只改变 H 的方向，不是维持基本功能的门槛。
Q / 元素爆发

三体归零·雪原校准

先将非零衡标归零；巡衡仍在时建立至多 12 秒的零点测区，让两只猫互相补足响应。

伴随响应只显示规则允许的伤害/控制反馈，不额外移动 H 或制造元素附着。
Passive / 固有天赋

把稳定写成被动

外观不可作为量值 — H 停留在同一端点时积累稳定读数，离开端点时清除；不研究归衡也能稳定发挥。

误差本身也是记录 — 完整归衡打开短暂校准窗口，提高当前场上角色的抗打断，不提供直接反应增伤。

雪原札记 — 至冬显示区域特产位置，风雪与极寒中非战斗移动更省力；靠近普通猫时它们不会立刻逃跑。

三项被动都不增加需要额外盯住的资源条；奖励来自你已经做出的路线选择。

轻相 / 普莎

普莎缓缓离地，雪粒反常地向上飘动。它负责牵引与多目标控制；大型敌人主要收到移动限制。

03 / Storyboards + Motion

每个动作都要有落点

这是第一批的静态制作板：不替代动画，但把姿态、镜头、猫、命中帧、可取消点、位移和总时长先锁成可讨论的语言。

阅读方式 / FRAME → FEEDBACK → HANDOFF

时间是表现目标，不改写玩法规格；命中帧是玩家看到反馈的节点，可取消点是交后台或进入下一拍的节点。BOARD 02–04 同时呈现静态画面与动作试片。

6 sequences · 3 motion clips
BOARD 01 / NA

霜度测录 · 四段普攻

总时长目标 1.82 s

用书页与环的轴向变化做四段区分，不让普通攻击误读成 H 输入。

  1. 0.00–0.38一段：拇指压住书脊，环向前翻出；0.21 命中，0.29 可取消。
  2. 0.38–0.78二段：记录册竖起，环从肩侧落下；普莎尾巴只带起识别弧线。
  3. 0.78–1.23三段：两层环交叉，伊嘉抬头但不响应；1.04 命中。
  4. 1.23–1.82四段：半册合上再展开，两猫同时看向中心；1.56 命中，1.69 可接重击。
镜头位移预算：四段分别约 0.10 m / 0.12 m / 0.06 m / 0.18 m；不是新增战斗位移规则。
BOARD 02 / E-OPEN

双相巡衡 · 首次施放

总时长目标 0.90 s

先写入中心 `0`，再让两只猫进入左右轨道；UI 从“战技”切换为“归衡校读”。

  1. 0.00–0.18近景推到记录册扣锁，读数从空白亮起；语音 06 在约 0.16 进入。
  2. 0.18–0.46镜头拉至正面中景，两猫分别触盘；0.44 初次命中。
  3. 0.46–0.68镜头固定让玩家读清 H = 0；巡衡状态亮起，0.68 后可交后台。
  4. 0.68–0.90回常规战斗视角，猫留在左右边缘；首个巡衡刻度按自动时间轴等待，最近命中只用于优先锁定。
不在读数写入前让玩家看到端点特效；巡衡持续时间、附着与倍率以完整玩法规格为准。
BOARD 03 / LIGHT

普莎 · 轻端响应

响应时长目标 0.62 s

先上浮，再牵引；上行方向比亮度更重要，控制范围和敌人分类不在动作板中重新定义。

  1. 0.00–0.14耳朵先动，身体离盘；稀疏上浮粒子出现，轻端 `−` 先亮。
  2. 0.14–0.28普莎在目标群上方停住，开口弧线收紧；牵引预告圈出现。
  3. 0.28–0.620.28 主响应命中，尾巴形成二次上弧；H 向轻端移动一格。
到达轻端时增加两条上升刻线与更宽开口弧，不用单纯“更亮”表示强化。
BOARD 04 / HEAVY

伊嘉 · 重端响应

响应时长目标 0.66 s

重点是“落点确认”，不是击飞；Boss 保持原地，但压制与当前场上角色的重端护持必须清楚。

  1. 0.00–0.16伊嘉收身跃起，竖直预加载线向下；目标脚下出现不闭合裂纹。
  2. 0.16–0.36伊嘉落地，镜头只下压 8°；0.36 高削韧反馈，不使用击飞式大冲击。
  3. 0.36–0.66落点楔形收束为重心点；H 向重端移动一格，到达端点时当前场上角色显示护持边框。
到达重端时裂纹变成三条平行垂线；当前场上角色显示“重端护持”与短计时，不使用敌方“输出降低”标记。
BOARD 05 / RETURN

归衡校读 · 再次施放

表现时长目标 0.86 s

两条轨迹在中央交汇；普通归衡与完整归衡用不同的环形反馈区分。

  1. 0.00–0.18记录册合页，镜头从当前端点向中心平移；当前刻线开始收拢。
  2. 0.18–0.44普莎下降、伊嘉上跃；0.44 H 写入 0，归衡环向外扩张。
  3. 0.44–0.86普通归衡显示柔和闭环；完整归衡叠合轻、重半环；0.60 可交后台。
H 为 0 时再次施放只补发基础巡衡刻度且不重置自动时钟：动作板不出现归衡爆闪、微粒或校准窗口。
BOARD 06 / Q

三体归零 · 雪原校准

起手 1.34 s + 至多 12 s 场地循环 + 结束 0.70 s

爆发不是把猫收进法器，而是把娜蒂娅写成第三个锚点，再让场地保持可读。

  1. 0.00–0.54眼镜反光切到书页；两猫分别落盘；若 H 非零，先把刻线回到中心。
  2. 0.54–0.960.54 初始命中；三层环从偏心回正，镜头从半身拉到俯视。
  3. 0.96–1.34巡衡仍在时，三个锚点锁定零点测区；UI 不增加第二条资源条，并显示实际剩余时间。
  4. up to 12 s loop外圈、中心方标和猫轨道持续可见，随巡衡结束；主响应与伴随响应使用相反方向短线区分。
爆发结束时外圈向内收两圈，保留中心方标；语音 11 放在最后一圈收束之后。
04 / UI + VFX Language

三种状态，三种方向

轻端、重端、归衡不依赖色相差异才能成立；缩小、换背景或色弱阅读时，符号与运动方向仍然保留。

轻端 / 普莎

主色为冰青，辅色偏淡紫；开口上弧、向上箭头、稀疏上浮粒子。读数带 `−`，牵引预告圈向中心收紧。

重端 / 伊嘉

主色为暖金，辅色为深冰蓝；向下楔形、竖直落线、密集下沉裂纹。读数带 `+`；到达端点时，当前场上角色以平行垂线护框显示重端护持。

归衡 / 零点

主色为银白，辅色为冰蓝；闭合圆环包住中心方标，左右两侧同时收拢。读数带 `0`，完整归衡才叠合两种半环。

缩小24 px 图标仍有外轮廓、方向与符号。
换背景深色与浅色底都保留边框和中心标记。
色弱去除颜色后仍可由 − / 0 / + 与纹理判断。
