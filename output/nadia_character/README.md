# 娜蒂娅「两衡之间」HTML Review 包

这是一个面向阅读和赠礼的原创同人角色档案 review 包。

## 打开方式

- 直接双击 `index.html`，无需联网，先审阅角色档案页；
- 打开 `postcards.html`，点击卡片查看 24 张 150 x 100 mm 横版明信片的正反面；
- `assets/` 保存两套视觉资产：以简洁游戏内角色风为主要玩家展示基线，并保留独立的精致宣传风主视觉；
- 当前 Review 压缩包收录页面实际引用的图片与 20 条语音；两张亚克力实物效果图另存于 `assets/acrylic/`，工作目录中的旧备份和历史归档不进入交付包；
- `print/` 中的 PDF 是上一阶段样稿，新的最终 PDF 会在 HTML review 通过后重新输出；
- `nadia_character_html_review.zip` 是当前 HTML review 版压缩包；旧的 `nadia_character_delivery.zip` 不作为本轮最终包。

## 内容边界

成品将娜蒂娅作为独立的二次元原创角色呈现，不解释现实人物映射，也不把原始照片放进玩家版内容。原始母设定仍在项目 `docs/` 目录中。

## 亚克力尺寸结论

- 主推荐：选择供应商的 **15 cm 长边**，按当前 2:3 竖版构图制作，成品约 `100 x 150 mm`，建议 3 mm 透明亚克力并配透明底座；展示比例、阅读距离和当前母图像素密度最平衡。
- 备选：12 cm 长边约 `80 x 120 mm`，像素密度更高、便于携带；10 cm 适合作为小型桌面卡，20 cm 则对当前 1024 x 1536 母图需要更明显放大且占空间较大。
- `assets/acrylic/` 中两张图是带实体边缘的产品效果图，用于确认视觉和给供应商看；它们不是带刀模/出血的最终印刷生产文件。实际印刷应继续使用对应的原始主视觉，并由供应商确认出血、圆角和安全边距。
