01 / STATE MACHINE

五格状态，一次明确选择

基础协同不依赖反应；反应只改变路线，归衡由玩家主动决定。

-2轻端
-1轻偏
0归衡
+1重偏
+2重端
INPUT / 状态输入

向外与回中

  • Stellar Swirl：H -1，触发普莎主响应。
  • Stellar-Conduct：H +1，触发伊嘉主响应。
  • E 再施放：非零 H 直接回到 0。
  • Q：先结算归衡，再建立零点测区。
  • 端点同向溢出：刷新观测，不继续增加 H。
RETURN / 归衡等级

普通归衡与完整归衡

普通归衡：只到达 -1 或 +1 后回中，提供短暂聚拢与迟滞。

完整归衡：曾到达 -2 或 +2 后回中，同时施加轻、重端部分控制效果。

完整归衡打开 6 秒校准窗口：全队 Stellar 反应伤害提高 15%，当前场上角色受到的削韧降低 50%。

04 / TALENTS & CONSTELLATION

端点稳定，归衡获益

命座强化既有状态机，不添加替换核心玩法的新资源条。

PASSIVE / 固有天赋

稳定读数与校准窗口

外观不可作为量值：同端点反应最多累计 2 层；每层使对应主响应伤害与控制持续时间提高 10%。

误差本身也是记录：完整归衡打开 6 秒校准窗口，15% Stellar 反应增伤与 50% 削韧减免。

雪原札记：显示至冬特产，风雪与极寒环境非战斗移动体力消耗降低 15%。

C1 - C6 / 双衡仪座

围绕同一套循环成长

  1. C1：首次路线额外移动一格，该次响应 +20%。
  2. C2：端点响应 +25%，强化牵引与重端弱化。
  3. C3 / C5：战技 / 爆发等级 +3。
  4. C4：校准窗口 8 秒，反应增伤 30%，完整归衡恢复 4 能量。
  5. C6：伴随响应 100%，主动回中间隔 3 秒，并加快下一次端点进入。
05 / BUILD & TEAMS

辅助优先，伤害其次

构筑先保证爆发循环，再分配攻击与双暴。

SIGNATURE / 零点不是答案

542 基础攻击力 · 55.1% 充能

R1：后台伤害提高 24%；后台元素命中为全队提供 6% 元素伤害，最多 3 层，每 2 秒获得一层，持续 6 秒。

  • 队伍辅助：昔日宗室之仪 4 件
  • 后台伤害：黄金剧团 4 件
  • 主词条：充能 / 冰伤 / 双暴
  • 充能目标：单冰 190%–215%，双冰 165%–185%，专武 160%–180%
ROTATIONS / 循环

三种队伍原型

  1. 轻端：E → 两次 Swirl 到 -2 → Q 归衡 → 再推端点 → E 再施放归衡。
  2. 重端：把 Swirl 换成 Conduct，适合精英与首领战。
  3. 双路线：反向反应逐格回中，归衡校读作为确定性保险。
  4. 无反应：保留后台冰协同，但失去端点强化与完整归衡窗口。
