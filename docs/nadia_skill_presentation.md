### 已确认的产品取舍

- 技能页主交付仍是静态逐镜动作板。介绍视频 MVP 的镜头、关键帧与 Seedance 提示词见 `docs/nadia_video_plan.md`；成片进入分享包前，技能页保持静态动作板。
- 技能图标采用纯 SVG / 代码绘制，保证缩放、主题切换和后续修改的一致性。
- 双风格采用分层方式：设定层负责情绪与角色魅力，游戏内层负责动作、UI 与可读性；不为每个技能重复制作一套完整并排版本。

- 数值模拟独立于 `gameplay.html`，不把调参控件混入玩家版规格页，也不把开发模拟器放入公开分享包。

## 1. 两层视觉系统

### 1.1 设定层

设定层使用 `nadia_action_v2_anime.png` 作为情绪锚点：雪原、冰晶、风、记录册与两只猫的关系应被读成“同行中的异常”，而不是技能数值截图。设定层可以提高光影密度，但不得改变娜蒂娅的过肩深色轻波浪、眼镜、披肩、保暖裤、平底靴、测量环，以及普莎和伊嘉的品种特征。远景优先读到发型、披肩、双猫和左后腰 Linchpin 大形；中景确认眼镜与双环测量夹；近景再展示记录册、折叠尺、样本袋与猫零食袋。

### 1.2 游戏内层

游戏内层使用 `nadia_action_v2_ingame.png`、`nadia_h_light_v1_ingame.png`、`nadia_h_heavy_v1_ingame.png`、`nadia_h_zero_v1_ingame.png`、`nadia_pusha_v1_ingame.png` 与 `nadia_igla_v1_ingame.png` 作为参考。所有可执行表现必须先让玩家读到“当前 H 在哪一端、这次是向外还是回中”，再让玩家欣赏冰晶和猫的动作。

### 1.3 图标与状态 token

## 2. 静态逐镜动作板

时间均为动作表现的相对时间目标，不改写技能数值、ICD 或状态机。`命中帧` 指玩家应看到伤害或控制反馈的时间；`可取消点` 指娜蒂娅可以交给后台或进入下一个动作的视觉节点。角色位移是镜头设计预算，不是新的战斗位移规则。

### 2.3 轻相响应｜普莎

选择轻端后，响应时间从任意有效星反应触发起算。普莎不做瞬移：先被风托起，再让牵引弧线落向敌人。`0.28 s` 是主响应命中与方向锁定节点；控制的持续时间、范围和敌人分类以玩法规格为准。

| 时间轴        | 动作板画面                           | VFX / 方向                             | 玩家反馈                                 |
| ------------- | ------------------------------------ | -------------------------------------- | ---------------------------------------- |
| `0.00–0.14 s` | 普莎耳朵先动，身体离开左盘约半个身位 | 上行粒子稀疏出现；开口弧线由下向上长出 | 左端 `−` 标记先亮，不立刻闪全屏          |
| `0.14–0.28 s` | 普莎在目标群上方短暂停住             | 一条向上的弧线闭合一半，末端指向中心   | 牵引预告圈收紧；小型目标边缘出现轻蓝描边 |
| `0.28–0.62 s` | 普莎慢慢落回轨道，尾巴形成二次弧线   | 轻端冰粒向上漂，命中点保持明亮而不爆炸 | 主响应完成；H 向轻端移动一格             |

到达轻端时，背景 UI 使用更宽的开口弧和两条上升刻线，而不是简单把颜色变亮；这样端点强化和普通轻端都能在形状上区分。

### 2.4 重相响应｜伊嘉

选择重端后，响应时间从任意有效星反应触发起算。伊嘉的重点是“落点确认”，不是把敌人夸张地击飞。无法位移的敌人保持原地，仍显示高削韧与较高伤害反馈；到达重端时只强化端点读数，不为当前场上角色添加减伤边框。

| 时间轴        | 动作板画面                | VFX / 方向                           | 玩家反馈                                             |
| ------------- | ------------------------- | ------------------------------------ | ---------------------------------------------------- |
| `0.00–0.16 s` | 伊嘉收身，从右侧盘边跃起  | 细竖线向下预加载；重端 `+` 标记变粗  | 目标脚下出现不闭合裂纹                               |
| `0.16–0.36 s` | 伊嘉落地，镜头只下压 `8°` | 冰裂沿地面向外走，不使用击飞式大冲击 | `0.36 s` 高削韧反馈，移动目标出现深蓝边框            |
| `0.36–0.66 s` | 伊嘉抬头，停在低位轨道    | 下沉楔形收束成一个金色重心点         | H 向重端移动一格；到达端点时 `+2` 与三条垂线加亮    |

到达重端时，落点裂纹变成三条平行垂线并强化命中数字的重量感；不显示减伤护框，也不使用敌方“输出降低”标记。重端巡衡期间，范围内敌人显示冰 / 雷减抗刻痕；进入范围即出现，离开即移除，与校准抗打断边框分开。

### 2.5 再次施放｜归衡校读

| 时间轴        | 姿态与镜头                             | 猫的参与方式                               | 命中 / 控制反馈                                      | 可取消与位移                      | 声音节点                             |
| ------------- | -------------------------------------- | ------------------------------------------ | ---------------------------------------------------- | --------------------------------- | ------------------------------------ |
| `0.00–0.18 s` | 记录册合页，镜头从当前端点向中心平移   | 普莎从上方轨道、伊嘉从下方轨道同时转向中心 | 当前 H 的刻线开始向 `0` 收拢                         | 不位移                            | 细微指针回弹                         |
| `0.18–0.44 s` | 正面中心构图；两猫轨迹交叉但不重叠角色 | 普莎下降、伊嘉上跃，形成上下对称           | `0.44 s` H 写入 `0`；归衡环向外扩张                  | `0.60 s` 可交后台；控制场继续显示 | 语音 09 在 `0.50 s` 左右             |
| `0.44–0.86 s` | 镜头退回战斗视角                       | 两猫回到娜蒂娅两侧                         | 普通归衡显示柔和闭环；完整归衡显示轻、重两种半环叠合 | 角色不额外位移                    | 低频收束；完整归衡多一声玻璃质感泛音 |

H 为 0 时再次施放只补发一次基础巡衡刻度，且不重置自动刻度时钟；动作板必须显示“读数未移动、没有归衡爆闪”，防止玩家误判为免费归衡。

完整归衡保留端点的视觉记忆，以8秒额外增伤环与抗打断边框表现；范围减抗从巡衡启动即存在，不在归衡时才出现。

### 2.6 元素爆发｜三体归零·雪原校准

爆发分为起手、零点测区循环和结束三个可剪辑单元。爆发的完整规则、持续时间、伴随响应和能量要求以玩法规格为准。

#### 起手 `0.00–1.34 s`

1. `0.00–0.20 s`：镜头从娜蒂娅眼镜反光切到记录册；若 H 非零，先让当前端点刻线回到中心，不先播完整归衡特效。
2. `0.20–0.54 s`：普莎落上左侧测量盘，伊嘉落上右侧测量盘；两盘明显出现轻与重的不同倾角。
3. `0.54 s`：爆发初始命中。三层环从书页中心穿出，先是偏心，再迅速找回中心。
4. `0.54–0.96 s`：娜蒂娅抬眼，镜头从半身拉到俯视；三点开始围绕同一圆周。
5. `0.96–1.34 s`：巨大冰蓝圆环锁定“零点测区”；UI 同时出现 `普莎 / 娜蒂娅 / 伊嘉` 三个锚点，不使用额外资源条。

#### 场地循环 `至多 12 s`

- 场地仅在巡衡仍存在时保持，并显示 `min(12 秒，巡衡剩余时间)` 的实际剩余时间；不使用持续满屏雪雾遮挡目标。
- Q 不立即补发刻度或倒退既有时钟；下一次已排定刻度照常结算，之后才使用爆发节拍。每次主响应与伴随响应的先后关系用两种不同方向的短线区分。
- 轻端由普莎主响应、伊嘉伴随；重端相反。两者为直接星反应冰伤，类型跟随实际反应，不附着、不递归写H；巡衡刻度独立挂冰。原生辉映不因选路改变。

#### 结束 `0.00–0.70 s`

1. 场地外圈从外向内收两圈，中心方标保留最后一帧。
2. 普莎和伊嘉回到娜蒂娅身边；不要把它们收进法器或写成可牺牲资源。
3. 语音 11 放在最后一个环收束之后；UI 回到常规巡衡状态或空闲状态。

## 3. 玩家版技能文案

### 普攻｜霜度测录

操纵记录册与测量环进行四段冰元素攻击，不直接改变H。

### 元素战技｜双相巡衡

打开记录册后，巡衡刻度即使在后台也按固定时间自动挂冰，并提供团队星反应增益与路线范围减抗。长按选轻重，短按沿用；两种星反应都积累所选方向。校读归衡保留本轮成长，冷却就绪后再施放则续开巡衡。

玩家教学分三层：第一层只讲“选轻或重 → 有效星反应让所选的猫记录 → 两次响应到端点 → 可主动回中”；第二层才展示五格 H、成长保留与切路清空 H；第三层解释校读间隔、归衡奖励节流、Q 测区和附着 ICD。第一层同时说明 E 后可以切后台，轻端牵引并减冰风抗，重端压制并减冰雷抗。切路不是逐格回中，也不发归衡奖励。

### 元素爆发｜三体归零·雪原校准

先归衡，再造成冰伤；巡衡存在时建立至多12秒测区。另一只猫提供直接星反应伴随，无附着、额外H或粒子。挂冰由独立巡衡刻度承担。

### 固有天赋与命座

两衡之间启用两种星反应；衡标提供可保留的本轮团队成长；完整归衡提供额外增伤与抗打断。C1加速首次到端点、C2团队擢升、C4支付Q后返能、C6三元素减抗与更强伴随。详细数值以玩法规格为准。

## 5. 独立模拟器契约

开发页 `tools/nadia_skill_simulator.html` 使用 `tools/nadia_simulator_core.js`。原生反应作为外部事件输入；不求解原生反应场地、附着消耗、整队DPS或真实物理。

必须覆盖：前后台输入、事件去重与共享GCD；主动选路、混合反应同向积累、归衡保留成长；22秒巡衡与18秒续开；Q不重排刻度、精确边界；目标失效与换波减抗；普通冰与两种直接星反应系数分列；独立刻度附着与主动攻击标准ICD；C0至C6；显式能量、Q支付与C4返还；装备触发后生效；死亡清理。

运行 `node tools/test_nadia_simulator.cjs`。日志公开外部输入、拒绝原因、命中、附着与能量溢出；输出不称为实战证明。
