# 娜蒂娅 v3.1：C0R0 整队替换预算

> 内部情景模型，运行 `node tools/nadia_team_budget.cjs`。输出为归一化的伤害预算指数，不是实战 DPS、KQMS 表格或角色强度榜。

## 对照与输入

- 替换位：娜蒂娅 C0 无专武与奥黛塔 C0 无专武；同一 20 秒事件账本、同等圣遗物质量，不计命座与专武。SSC 参照奥黛塔 / 八重神子 / 桑德萝涅 / 七七；SSW 参照奥黛塔 / 梦见月瑞希 / 冰旅行者 / 砂糖。配队与奥黛塔技能口径来自 [KQM 奥黛塔指南](https://keqingmains.com/q/odette-quickguide/)；星反应乘区来自 [KQM Stellar 反应指南](https://keqingmains.com/misc/stellar-reaction-guide/)。参照队友只是场景标签，未计算其逐招倍率。
- 统一基线：敌人初始对应抗性 10%；SSC 每轮七个星超导事件，队友原始星伤 100 单位、对应普通伤害 60 单位、中性伤害 20 单位；SSW 八个星扩散事件，分别为 150 / 45 / 20。混合队八个风雷交替事件为 110 / 50 / 20。每次事件均匀分配这些预算。SSW 的 150 是多目标情景假设，不是游戏里已验证的怪物数量或场地倍率。
- 奥黛塔按 **有利于参照方的满额口径**计算：60% Stellar DMG、14% Stellar Base DMG、非外部炉心场景另给 50% 炉心增伤，默认所有事件都覆盖；个人输出设为每轮 18 个归一化单位，场上占用估为 1.5 秒。实际后台命中、增益时长及其个人输出仍须实测。
- 娜蒂娅路线与团队增益逐事件读取 `nadia_simulator_core.js` 的状态；普通冰和 Direct Stellar 伤害从命中日志分别换算，每 1% 倍率暂记 0.007 / 0.011 单位。这是**显式可替换的预算系数**，不表示两类倍率能直接相加。默认全部队友伤害与对应路线减抗元素匹配；敏感性另外测试仅 50% 匹配。
- `其他角色持有炉心` 时，两边均只获得一次外部 50% 套装增伤，娜蒂娅自己不再装备炉心；不另造宗室替代收益。`已有 40% 外部减抗` 先施于两边，再叠娜蒂娅路线减抗。换波设 10–13 秒娜蒂娅减抗目标失效、同时间队友仍能攻击；不开 Q 与少一次归衡使用同一事件量，专门隔离这些操作的损失。
- 充能列给出以 180% 充能、首发 E 的四冰微粒前台接球、首次主响应的一冰微粒后台接球为前提，为**下一轮 Q**另需的外部基础能量；起始轮设为满能。生存位均由第四名队友承担，娜蒂娅本身无治疗、护盾或生命值减伤。

## 稳健性与决策

| 减抗可覆盖伤害比例 | 奥黛塔增益覆盖 | 八情景中娜蒂娅领先超过 10% 的数量 | 比值区间 |
| ---: | ---: | ---: | ---: |
| 50% | 75% | 5 | 1.054–1.150 |
| 50% | 100% | 0 | 0.980–1.069 |
| 100% | 75% | 8 | 1.139–1.246 |
| 100% | 100% | 4 | 1.065–1.159 |

**本轮不调整核心数值。** 默认表确实提示路线减抗在高匹配队伍中可能很强，但「多数场景持续超过 10%」对减抗可覆盖比例与参照方覆盖率都不稳健。这个模型还缺真实原生反应伤害、元素消耗、场地倍率、队友招式、敌人韧性、换波损失与逐帧站场，因此不足以触发 `baseBonus 40→35` 或猫倍率上调。下一步需用同等构筑的完整轮转表或实机原型替换归一化输入，先验证哪部分队友伤害真正吃到路线减抗。
