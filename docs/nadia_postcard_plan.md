# 娜蒂娅「两衡之间」明信片套组规划

> 当前阶段：HTML review。HTML 通过后，才输出最终印刷 PDF。2026-09-04 已按当前内容重建最新屏幕预览（档案 20 页 + 明信片 48 页，`output/pdf/`）；仍为 review 预览，不替代 HTML 通过后的最终印刷版。

## 结论

明信片采用横版 150 x 100 mm、双面印刷。正面是收藏和视觉记忆，背面是一个主题的角色记录。推荐先按 24 张完整套组评审，不把 PDF 页面直接缩小到明信片尺寸。

本轮采用双视觉模式，但设定了明确的优先级：简洁的游戏内角色风是玩家页面、角色卡和大多数明信片的默认基线；精致宣传风只保留在少数封面和剧情节点，作为同一角色的宣传主视觉。两者共享人物识别锚点，但不把精致人像误当成游戏内卡面。

三种载体共享同一份角色事实、文案和视觉规范，但不采用完全相同的布局：

| 载体 | 主要任务 | 适合的内容密度 | 交互/阅读方式 |
| --- | --- | --- | --- |
| HTML | 先审阅整体风格、内容和信息顺序 | 最完整 | 长页面、章节导航、衡标互动、明信片翻面 |
| 角色档案 PDF | 正式、连续、可保存的角色介绍 | 完整但经过编辑 | 按章节阅读，适合屏幕和后续印刷 |
| 明信片 | 收藏式阅读和实体展示 | 一张一个主题 | 正面看图，翻到背面读记录 |

## 尺寸与排版基线

- 成品：150 x 100 mm，横版 3:2。
- 工作画布：156 x 106 mm，四边各 3 mm 出血。
- 安全区：裁切线内至少 5 mm；脸部、角色名、关键测量环和猫眼不要贴边。
- 输出：正面和背面分别校对方向，再合并为印厂 PDF；保留屏幕 RGB 版和按印厂要求制作的 CMYK 版。
- 纸张：建议 300 g 左右哑光铜版纸或高白卡；大面积深蓝需要先做一张打样。
- 背面：不预留传统邮政格式，作为赠礼收藏卡使用。若需要手写寄语，另加一张专门的留白卡，不挤占角色资料卡。

## 可选扩展卡

如果 24 张卡的背面仍有明显空余，不直接增大字号或拉长行距，而是新增 4 张附录卡：

1. **雪原札记**：至冬探索中的风向、积雪和承重观察。
2. **安全牵引绳**：普莎的日常照护记录，以及娜蒂娅如何处理“会飘的猫”。
3. **旧设施剖面**：只解释三体锚定现象，不扩展成世界宇宙学谜团。
4. **三体记录页**：把“双体异常长期观测记录”改成“三体异常长期观测记录”的完整场景。

这些卡应作为剧情附录，不承担角色基础资料；是否加入，以 HTML review 中的实际留白和阅读节奏为准。

## 内容同步原则

- HTML 是第一审阅稿，先确认新视觉、UI、信息顺序和文字密度。
- PDF 使用同一份已确认的角色文案，但改成连续的章节版式，可加入跨页、目录和完整故事段落。
- 明信片使用同一份事实和短文案，但按一张卡一个主题重新排版；不能只把 PDF 页面截图缩放。
- 精致宣传风图片只承担少数封面和剧情情绪节点；游戏内角色风图片承担识别、机制、状态和大多数角色展示。它们是同一角色的两种展示层，不是两套角色设定。
- 本轮新增场景图按语义跨 HTML 与明信片复用，但同一套明信片不再重复使用高显著人物场景；第 01 张保留原精致封面，第 17 张使用独立的精致剧情主视觉。
- 核心道具采用无文字独立图：专属法器、双衡测量环、观测记录册；HTML 道具区完整展示，明信片优先使用法器和测量环，料理卡继续保留角色料理。
- 每张卡的图片必须在自身 3:2 画布内完成主体表达；垂直主立绘只能使用 `contain` 或用于 HTML/PDF主视觉，不再用 `cover` 截取人物或猫咪来充当机制图。
- 背面采用居中信息卡排版：标题、正文和小标签整体垂直居中；正文字号由 HTML 根据字数动态计算，长文案缩小，短文案放大，最终印刷稿再以 150 x 100 mm 实际尺寸复核。
- 如果明信片新增了剧情，必须先回写玩家版角色文档，再同步 HTML 和 PDF，避免三套内容产生冲突。
- `assets/archive/` 只保存历史草稿；当前两张旧的最新图可作为风格和身份参考，但不进入最终玩家包。新生成的高动漫化图使用独立的版本文件名。
- HTML 档案页额外收录 20 条中文普通话独立语音；语音是电子包功能，不把播放控件硬塞进纸面卡片。明信片第 23 张只保留语音主题和台词摘录。

## HTML review 重点

1. 新主视觉是否已经摆脱真人肖像感。
2. 角色页和明信片页是否具备游戏角色介绍的层级、徽记、元素色和动势。
3. 150 x 100 mm 卡片缩小观察时，标题、人物剪影、猫咪方向和背面正文是否仍然清楚。
4. 24 张是否有某些卡片过空或过密；只有确认节奏后，才决定是否加入 4 张剧情附录卡。
