# 娜蒂娅角色设定逻辑审阅与修订基线

> 本文件是创作与制作内部用的审阅记录，不是送给玩家的角色档案。原始母设定仍保留在 `genshin_character_full_design.md`，本文记录将被带入玩家版的修订。

## 结论

角色的情感核心、视觉识别点和玩家印象曲线成立。最需要修订的不是人物，而是两个边界：

1. 把现实物理中的“质量”改写为提瓦特语境中的“锚定负荷”。
2. 把“衡标”从概念表变成一套可以被玩家理解、被策划实现的状态规则。

这样既保留“胖的会飘、瘦的很重”的第一印象，也避免真实质量带来的惯性、重力和生理后果无法解释。

## 必须修订的逻辑点

| 原问题 | 影响 | 修订口径 |
| --- | --- | --- |
| 猫的异常被写成真实质量改变 | 伊嘉的运动、重力、落点和周围环境会远超设定描述；普莎也不应只是“轻一点” | 改成只作用于与外界接触时的“锚定负荷”。它影响抱起、承重、落地、受风和仪器读数，不改变猫的生理机能和基本动作 |
| 衡标有 -2 到 +2，但没有完整状态流程 | 玩家无法判断何时触发强化、归衡和重置 | 定义初始值、移动规则、端点规则、归衡规则和爆发重置规则 |
| 战技收益主要依赖风雷反应 | 没有风或雷时，“放战技即可获得稳定辅助”的承诺不成立 | 战技启动后先让两只猫进入巡衡并提供低频基础冰元素协同；风雷反应再改变路线和强化方式 |
| “连续触发”没有衰减、冷却或上限 | 可能变成无限叠层，且普通玩家无法理解 | 同类反应只在端点刷新或强化对应观测状态，不继续超过端点；具体冷却与倍率留给战斗测试 |
| 7.0 术语与原创扩展混在一起 | 玩家容易误解哪些是官方资料 | 玩家版加版本基线和同人声明；内部版单独列出“官方语境”和“娜蒂娅原创规则” |

## 修订后的核心机制

### 三者关系

旧设施并没有把某种物质从一只猫搬到另一只猫。它把三名相互连接的生命标记成同一个测量系统：

- 普莎承担偏向外侧的轻相表现，容易脱离地面；
- 伊嘉承担偏向内侧的重相表现，接触地面时施加异常负荷；
- 娜蒂娅是第三锚点，负责让两种表现保持在可生活的范围内。

“重”不是猫的真实质量，而是锚定关系在接触和测量时表现出的负荷。“轻”也不是失去身体，而是对地面和空气的锚定减弱。

### 衡标规则

内部实现采用一个五格状态变量 `H`，取值为 -2、-1、0、+1、+2：

1. 元素战技启动时，`H = 0`，两只猫进入巡衡状态。
2. 有效触发 Stellar Swirl 时，`H` 向轻端移动一格，并触发普莎响应。
3. 有效触发 Stellar-Conduct 时，`H` 向重端移动一格，并触发伊嘉响应。
4. 到达 -2 或 +2 后，进入对应的“轻端观测”或“重端观测”。同类反应只刷新或强化该状态，不继续叠出第三格。
5. 反向移动回到 0 时触发一次“归衡响应”，然后恢复中性状态。
6. 元素爆发建立“零点测区”，将 `H` 设为 0，并在持续期间让另一只猫提供弱化的伴随响应。
7. 没有风或雷反应时，猫仍然存在并提供基础协同，但不会进入轻端、重端或归衡强化。

状态的具体持续时间、触发冷却、伤害和控制强度必须在战斗测试后确定；玩家版不写未经测试的倍率。

## 战斗定位收束

娜蒂娅的唯一主卖点是：

> 通过 Stellar 反应改变战场控制方式，再把失衡带回可控状态。

她可以有后台冰元素、聚拢、压制和反应强化，但这些都是主卖点的服务项，不再把她包装成同时拥有所有辅助能力的泛用答案。

普通玩家的体验是：战技召出两只猫，获得稳定的基础协同；高阶玩家才会主动在轻端、重端和归衡之间循环。

## 世界观修订口径

- “有效质量”统一改写为“锚定负荷”“承重响应”或“读数异常”。
- 娜蒂娅不是旧设施的实验对象，也不是提瓦特世界的核心人物。
- 她的 Cryo Stellar Linchpin 是当年三体锚定关系的第三部分，不是后来突然获得的外挂能力。
- 旧设施只证明过去有人研究过“属性在锚定对象之间重新分配”的现象，不解释整个世界的宇宙学。
- “样本数量填错了”保留为人物性格笑点，不再作为异常重新失稳的物理原因。

## 视觉结论

人物应采用明确的二次元角色立绘，而不是真人照片写实化：

- 成人动漫比例，清晰线稿，赛璐璐分色；
- 眼镜、黑色轻波浪、温柔知性表情作为识别点；
- 服装用大形状建立轮廓，不堆叠写实口袋和金属零件；
- 两只猫保持真实猫的轮廓，但与人物使用同一套二次元绘制语言；
- 原始人物与猫咪照片仅作为参考，不放入玩家版主文档。
