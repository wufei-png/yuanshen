# 娜蒂娅第三版：定位审计、建议取舍与验证记录

日期：2026-09-15。经用户确认：稳定辅助为主、独立核心、主动选路；游戏技术细节自主确定，整版方案获准同步实施。现行规则为 [玩法规格](../nadia_gameplay_system.md)，外部意见 [advise1.md](advise1.md) 保留原样，不作为现行规格。

## 结论与实施范围

第二版将零命直接星反应增幅列为非目标，与新的T0辅助目标冲突。第三版补齐稳定辅助的机制条件；其强度仍是待整队比较的设计基线，不能把结构测试或简化算式写成实战T0。

已同步：玩法规格、母设定战斗章节、逻辑审阅、玩家版战斗摘要、技能表现、收藏卡计划、五个公开HTML、两份PDF与分享ZIP。新增可复用开发核心与15组规则回归；公开玩法正文由唯一规格生成，内部测试与核心不进入分享包。

## 已完成的结构与数值检查

### 原版复核

使用Node VM运行原HTML的真实内嵌脚本（DOM仅做适配），复现轻2240、重2527、混合2343.5、无反应1143的系数总计。两次完整归衡在5.5 / 11.5秒，原6秒窗口合计12秒。交替两类反应可反复回0而不达端点。

旧版15%减抗、10%原抗性、无其他减抗与均匀伤害假设下：窗口内对应伤害提升13.89%，60%覆盖时整段约8.33%。不是整队伤害提升。

### 简化替换敏感性

只固定同一星反应伤害来源，不模拟双方自身输出。记B为已有星反应增伤，r为已有减抗后的抗性，R为原生抗性乘数：

```text
娜蒂娅 / 奥黛塔 = (1+B+娜蒂娅增伤)/(1+B+0.60) / 1.14 × R(r-0.30)/R(r)
R(r<0) = 1-r/2；0<=r<0.75时 R(r)=1-r
```

B=0.50、原抗性0.10时：成长完成相对102.1%，归衡窗口112.3%。已有40%其他减抗时分别94.4% / 103.9%。其他增伤从50%提高至150%时，成长完成相对比约102.1%-103.8%（无其他减抗），94.4%-96.0%（已有40%减抗）。

这种比较只是参数预算依据。不能把窗口峰值当全程，不能忽略挂冰、场地、暴击、队伍位置与个人输出，更不能将两个辅助同名炉心各算50%。
