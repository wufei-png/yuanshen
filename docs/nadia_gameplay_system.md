# 娜蒂娅玩法系统规格｜衡标 H

> 状态：已确认方向后的第一版可推演数值稿  
> 角色定位：五星冰元素法器，后台协同 / 控场 / 状态管理  
> 设计边界：独立同人角色优先；兼容 Stellar 语汇，但不依赖任何指定角色才能完成基础循环。  
> 验证边界：本文是内部平衡目标，不代表真实游戏环境、服务器逻辑或正式数值测试结果。

本文是娜蒂娅战斗设计的唯一详细规格。母设定、玩家版、HTML、角色档案 PDF 与收藏卡只摘录本文，不再各自发明机制。

---

## 1. 已锁定的设计结论

1. Stellar Swirl 与 Stellar-Conduct 负责把衡标推向轻端或重端。
2. 元素战技再次施放与元素爆发都可以主动把衡标带回 0。
3. 单风、单雷与双路线队都能完成“失衡 - 归衡”循环，不强制风雷同时入队。
4. 没有对应反应时，元素战技仍提供完整时长的后台冰元素协同。
5. 主要价值是控场、战场稳定与短窗辅助；个人伤害是次级预算。
6. Boss 不被强制击倒。无法位移的敌人仍可承受重端的减伤害输出标记与归衡辅助收益。

### 非目标

- 不做最高数值的 Stellar 专职增伤器。
- 不让玩家为了维持基本挂冰而持续盯住五格 UI。
- 不用自动回中取代玩家选择；自动化仅存在于高命或爆发的伴随响应中。
- 不把两只猫写成召唤物、元素生命或可牺牲资源。

## 3. 衡标状态机

```text
普莎 / 轻端                                  伊嘉 / 重端
   -2  <----  -1  <----  0  ---->  +1  ---->  +2
                         归衡

任意非零状态 -- 再次施放元素战技 --> 0
任意非零状态 -- 施放元素爆发 ------> 0
```

### 3.1 状态变量

| 变量 | 取值 | 说明 |
| --- | --- | --- |
| `H` | -2, -1, 0, +1, +2 | 当前衡标位置 |
| `endpoint` | 无 / 轻端 / 重端 | 本次偏移是否曾到达端点 |
| `patrol` | 开 / 关 | 双相巡衡是否存在 |
| `zero_field` | 开 / 关 | 零点测区是否存在 |
| `return_grade` | 普通 / 完整 | 回到 0 时采用哪一种归衡响应 |

### 3.2 输入事件

| 事件 | 状态变化 | 结果 |
| --- | --- | --- |
| 首次施放战技 | `H = 0`，清除端点记录 | 开启 18 秒双相巡衡 |
| 有效 Stellar Swirl | `H = max(-2, H - 1)` | 普莎主响应 |
| 有效 Stellar-Conduct | `H = min(+2, H + 1)` | 伊嘉主响应 |
| 战技再次施放 | 非零时直接 `H = 0` | 触发归衡响应 |
| 战技再次施放，且 `H = 0` | 状态不变 | 立即补发一次巡衡刻度，不产生归衡增益 |
| 施放爆发 | 先把非零 `H` 归零 | 结算归衡后建立零点测区 |
| 巡衡结束 | 清除 `H` 与端点记录 | 两只猫回到娜蒂娅身边 |

### 3.3 端点与归衡判定

- 到达 -2 或 +2 时记录本次偏移已经到达端点。
- 从只到达 -1 或 +1 的偏移回到 0，触发“普通归衡”。
- 从曾到达 -2 或 +2 的偏移回到 0，触发“完整归衡”。
- 回中方式可以是相反路线反应、战技再次施放或元素爆发。
- 回到 0 后立刻清除端点记录；下一次偏移重新计量。
- 归衡响应有 4 秒独立触发间隔。间隔内仍会正确归零，但不会重复造成归衡伤害或刷新增益。

### 3.4 端点溢出

当 H 已经处于 -2 或 +2，同方向反应不会继续累加 H，也不会无限叠加数值。它只会：

1. 刷新对应端点观测的持续时间；
2. 触发对应猫的协同伤害；
3. 为固有天赋“外观不可作为量值”累计稳定读数。

## 5. 元素战技｜双相巡衡

娜蒂娅打开记录册，造成一次范围冰元素伤害，使普莎与伊嘉进入持续 18 秒的“巡衡”状态，并将 H 设为 0。

### 5.1 基础协同：巡衡刻度

巡衡期间，当前场上角色对敌人造成伤害时，测量环每 2 秒发动一次范围冰元素协同攻击。

- 不需要 Stellar 反应即可触发。
- 不要求娜蒂娅留在场上。
- 只追踪当前场上角色命中的敌人，不主动攻击场外目标。
- 初次施放产生 3 个冰元素微粒；本次巡衡第一次触发猫响应时额外产生 1 个，合计上限 4 个。

### 5.2 路线响应

有效触发 Stellar Swirl 或 Stellar-Conduct 时，对应猫发动主响应。两种主响应共享 2.5 秒触发间隔。

#### 普莎：浮量响应

- H 向轻端移动一格。
- 在 5.5 米范围内产生 1.0 秒柔和牵引。
- 小型敌人受到完整牵引；中型敌人移动速度降低 20%，持续 3 秒。
- 到达 -2 后进入轻端观测：范围扩大到 7 米，牵引持续 1.5 秒，中型敌人移动速度降低 30%，持续 4 秒。

#### 伊嘉：坠量响应

- H 向重端移动一格。
- 在 4.5 米范围内造成一次高削韧冰元素协同攻击。
- 可移动敌人的移动速度降低 25%，持续 4 秒。
- 到达 +2 后进入重端观测：刷新减速，并使命中敌人造成的伤害降低 10%，持续 5 秒。
- 无法位移的首领不被击倒，但伤害降低标记仍可生效。

### 5.3 再次施放：归衡校读

巡衡存在时，战技按钮切换为“归衡校读”，拥有独立的 6 秒使用间隔，不延长巡衡总时长。

- H 非零：直接把 H 设为 0，并按端点记录结算普通或完整归衡。
- H 为 0：立即补发一次巡衡刻度，只造成基础协同伤害，不产生归衡响应、微粒或校准窗口。

### 5.4 归衡响应

| 类型 | 触发条件 | 控制与辅助 |
| --- | --- | --- |
| 普通归衡 | 只到达 -1 或 +1 后回中 | 5 米范围柔和聚拢与迟滞，持续 2 秒 |
| 完整归衡 | 曾到达 -2 或 +2 后回中 | 6.5 米范围同时施加轻、重端 70% 的控制效果，持续 4 秒 |

完整归衡是操作收益的核心，但不是维持后台冰协同的前提。

## 6. 元素爆发｜三体归零·雪原校准

娜蒂娅把自己作为第三锚点写入测量，在大范围内造成冰元素伤害。

结算顺序：

1. 若 H 非零，先执行一次强制归零并按端点记录结算归衡；
2. 造成爆发初始伤害；
3. 建立持续 12 秒的“零点测区”。

### 6.1 零点测区

- 巡衡刻度的攻击间隔从 2 秒缩短到 1.5 秒。
- Stellar Swirl 触发普莎主响应时，伊嘉追加一次 55% 倍率的伴随响应。
- Stellar-Conduct 触发伊嘉主响应时，普莎追加一次 55% 倍率的伴随响应。
- 伴随响应不移动 H、不产生元素附着、不生成元素微粒。
- H 仍然可以正常向端点移动，玩家也可以使用归衡校读主动回中。

### 6.2 爆发参数

| 初始伤害 | 208.0% | 263.0% | 309.0% | 348.0% |
| 伴随响应倍率 | 主响应的 55% | 主响应的 55% | 主响应的 55% | 主响应的 55% |

## 8. 固有天赋

### 8.1 外观不可作为量值

H 停留在同一端点时，再次触发对应路线会获得 1 层“稳定读数”，最多 2 层；离开端点时清除。

每层使对应猫主响应造成的伤害提高 10%，控制持续时间提高 10%。这让单路线队在端点停留时仍然有稳定收益，但不会无限成长。

### 8.2 误差本身也是记录

触发完整归衡后，全队获得 6 秒“校准窗口”：

- Stellar 反应造成的伤害提高 15%；
- 当前场上角色受到的削韧降低 50%，提高抗打断能力。

校准窗口不可叠加，重复触发只刷新持续时间。其数值低于专职反应增幅角色，避免娜蒂娅从控场辅助变成纯增伤替代品。

### 8.3 雪原札记

在至冬显示附近区域特产的位置。风雪与极寒环境中的非战斗移动体力消耗降低 15%。靠近部分普通猫时，它们不会立即逃跑。

## 9. 命之座｜双衡仪座

### C1 第一条：不要相信眼睛

每次开启双相巡衡后，H 第一次发生路线变化时额外移动一格，该次主响应伤害提高 20%。单路线队可以用第一次反应直接进入端点观测。

### C2 第二条：重新称量

端点主响应伤害提高 25%。轻端对中型敌人的牵引按小型敌人 40% 的强度生效；重端使敌人造成的伤害降低效果从 10% 提高到 15%，持续时间延长到 7 秒。

### C3 第三条：记录直到一致

双相巡衡的技能等级提高 3 级，至多提升至 15 级。

### C4 第四条：误差从不是零

“校准窗口”持续时间延长到 8 秒，Stellar 反应伤害提高效果从 15% 提高到 30%。触发完整归衡时为娜蒂娅恢复 4 点元素能量，该效果每 6 秒至多触发一次。

### C5 第五条：零点只是起点

三体归零·雪原校准的技能等级提高 3 级，至多提升至 15 级。

### C6 最后一条：我们三个都在这里

零点测区期间：

- 伴随响应从主响应 55% 提高到 100%，并获得对应控制效果；
- 归衡校读的使用间隔从 6 秒缩短到 3 秒；
- 每次完整归衡后的第一次路线变化额外移动一格。

C6 把“管理天平”转成高速主动振荡，但仍由玩家决定什么时候回中。

## 12. 队伍原型与循环

### 12.1 轻端单路线

**娜蒂娅 + 风元素触发位 + 主输出 + 生存位**

```text
娜蒂娅 E -> 两次 Stellar Swirl 到 -2 -> Q 完整归衡
-> 零点测区内再次推到 -2 -> E 再次施放完整归衡 -> 主输出收尾
```

价值：多目标聚拢、较高控制覆盖、两次可控校准窗口。

### 12.2 重端单路线

**娜蒂娅 + 雷元素触发位 + 主输出 / 驱动位 + 生存位**

```text
娜蒂娅 E -> 两次 Stellar-Conduct 到 +2 -> Q 完整归衡
-> 再次推到 +2 -> E 再次施放完整归衡 -> 主输出收尾
```

价值：精英与首领战稳定、减速、降低敌人伤害输出。

### 12.3 双路线振荡

**娜蒂娅 + 风元素位 + 雷元素位 + 主输出或生存位**

反向反应可以逐格把 H 带回 0；当元素顺序不稳定时，归衡校读仍然提供确定的主动回中。双路线提高上限，但不再是基本循环的硬性队伍税。

### 12.4 无 Stellar 反应

**娜蒂娅 + 任意主输出 + 两个功能位**

只使用巡衡刻度与爆发，仍有 18 秒后台冰协同和 60 能量爆发。此队伍不会获得端点强化与完整归衡窗口，属于可用但非最优的低操作模式。

## 13. 20 秒预算检查

以下采用 10 级技能、零命、单体完全命中，不计算暴击、抗性、增伤、爆发伴随响应与普通攻击。

| 场景 | 粗略倍率总计 | 设计结论 |
| --- | ---: | --- |
| 只放 E，无路线反应 | 101% + 9 x 68% = 713% | 保底后台协同，不抢副输出预算 |
| E + 5 次轻端响应 + 1 次完整归衡 | 1,478% | 控场优先，伤害较低 |
| E + 5 次重端响应 + 1 次完整归衡 | 1,603% | 单体略高，补偿聚怪价值较弱 |
| 上述循环追加 Q 初始伤害 | +309% | 整轮约 1,787% 至 1,912% |
| Q 内 4 次伴随响应 | 约 +231% 至 +286% | 完整轮总计约 2,020% 至 2,200% |

这一预算明显低于专职后台副输出，换取 18 秒挂冰、路线控制、主动归衡与短窗辅助。

## 14. 异常边界与验收规则

1. 同一伤害事件同时满足两类 Stellar 反应时，只按实际结算顺序移动 H，不并发写入。
2. 两只猫的主响应共享 2.5 秒触发间隔，避免一帧内双重位移。
3. 归衡伤害与校准窗口共享 4 秒触发间隔；H 的归零本身永远成功。
4. 爆发在 H = 0 时不伪造完整归衡，只建立零点测区。
5. 爆发伴随响应不附着元素、不移动 H、不生成微粒。
6. 巡衡结束或角色离队时，清除 H、端点记录、稳定读数与归衡校读状态。
7. 角色倒下时不保留后台巡衡，防止两只猫在无持有者状态继续结算。
8. Boss 与固定机关不接受位移；可接受的减速、伤害降低和队伍增益照常结算。
9. 合作模式中 H 归属于娜蒂娅实例；不同玩家的娜蒂娅不共享状态。
10. 所有数值进入实现前需要用单体、群怪、首领、低帧率与高延迟场景分别测试。

## 15. 后续测试优先级

1. 验证 18 秒巡衡与 15 秒爆发是否造成过高覆盖。
2. 验证 6 秒主动回中是否能稳定完成两次端点循环，又不会让 UI 过忙。
3. 验证轻端牵引在中型敌人上的强度，确保不替代专职聚怪角色。
4. 验证重端 10% 伤害降低在首领战中的实际价值。
5. 验证完整归衡 15% Stellar 短窗是否低于专职增幅角色、但足以奖励操作。
6. 验证 60 能量与 4 微粒的循环是否符合 160% 至 210% 的充能目标。
7. 验证 C6 三秒主动回中不会形成无限归衡结算。
