# 娜蒂娅玩法系统规格｜衡标 H

> 状态：第三版已确认设计 / 第一版平衡验证基线（2026-09-15）。
> 定位：五星冰元素法器 / Cryo Stellar Linchpin；稳定星反应辅助、独立队伍核心、后台副输出与轻重控场。
> 目标：零命非专武即可承担核心辅助，不依赖频繁切回；主动归衡提高上限。
> 验证边界：原创同人设计。结构测试与简化增益计算不是真实游戏或整队 DPS 证明，尚不能宣布实战 T0 或保证未来版本不淘汰。

本文是唯一详细玩法规格。母设定、玩家页面与印刷品仅摘录本文；历史草案和外部建议不构成现行规则。

## 1. 身份与基础属性

| 项目 | 规格 |
| --- | --- |
| 稀有度 / 元素 / 武器 | 五星 / 冰 / 法器 |
| 90级生命 / 攻击 / 防御 | 12,858 / 223 / 743 |
| 突破属性 | 暴击伤害38.4% |
| 基础循环 | 选路并施放E，切队友；后台成长，不强制每轮Q |
| 高阶循环 | 到端点后以校读或Q归衡，获得额外窗口 |
| 生存边界 | 无治疗、护盾或减伤；抗打断不能替代生存位 |

普通攻击10级：四段53.4% / 48.8% / 61.7% / 78.2%攻击力；重击156.4%，消耗50体力；下坠112.3%，低 / 高空冲击224.6% / 280.6%。普通攻击不直接写入H。

## 2. 星枢天赋｜两衡之间

娜蒂娅在自己的队伍中时，队伍角色触发的超导与冰元素扩散分别转为 Stellar-Conduct（星超导）与 Stellar Swirl（星扩散）。转换不要求娜蒂娅在场，也不要求巡衡存在。

该天赋只启用两种反应，不额外提供反应基础伤害提升。重复启用者不重复转换；其他角色自己的基础增幅按原生规则计算，不从“启用”推导出娜蒂娅具有同样增幅。

原生场地、伤害、能量、附着与辉映（Radiance）照常结算。娜蒂娅按原生条件进入辉映；选择轻重路线不强制切换辉映、不解除原生星超导优先规则，也不改变队友的伤害类型。

## 3. 元素战技｜双相巡衡

### 3.1 启动与续开

施放造成普通范围冰伤，开启22秒巡衡，冷却18秒。每次新巡衡清除H、本轮成长与首次响应标记，保留所选路线；最多存在一个巡衡。

- 初始默认为轻端。长按E切换所选路线；短按沿用选择。
- 无巡衡且E冷却就绪：短按启动，长按切路后启动。
- 有巡衡且距上次启动不足18秒：短按执行归衡校读；长按只切路，不产生伤害、粒子、归衡奖励或延长巡衡。
- 有巡衡且E冷却已好：短按续开；长按切路后续开。续开不把旧H当作完整归衡，不重置归衡、响应或切路节流。
- 归衡校读拥有独立6秒间隔；切路独立1秒间隔。Q不改变所选路线。
- 冷却未好且巡衡不存在时，E不能启动；长按仍可选择路线。

### 3.2 稳定辅助与范围

巡衡存在时，自己的队伍角色（含娜蒂娅、前后台）获得40%星反应伤害加成。同时，当前场上角色12米内的敌人按所选路线受到30%减抗：轻端为冰 / 风，重端为冰 / 雷。

减抗是随当前场上角色移动的有效范围，不绑定最初命中的敌人。敌人进入范围即获得，离开或巡衡结束即失去；切路立即替换减抗元素，不残留叠加。C6例外见命座。多名娜蒂娅的同名增益与减抗取最高，不叠加。

减抗不依赖H、端点或Q。新敌人进入有效范围即可受益。队伍增益不要求造成某种特定星反应，轻端和重端都能强化两种星反应；控制与减抗元素才是选路差异。

### 3.3 巡衡刻度与产球

首次刻度为启动后1.5秒，此后每2秒；零点测区内后续间隔为1.5秒。一次刻度只攻击一次，不按目标数量重复发射。刻度独立附着，每次有效命中附着1U冰，没有额外标准ICD。

优先锁定当前场上角色最近命中的有效敌人；失效或超出12米时转向12米内最近敌人。无有效目标则跳过，不补发、不暂停时间轴。无反应时仍完整保留刻度、基础增益和范围减抗。

启动或续开的初始攻击命中有效敌人时产生4个冰微粒；本轮第一次实际命中的猫主响应额外产生1个。无命中不产球，重施校读与伴随不产球；每轮上限5个。

## 4. 衡标与轻重路线

### 4.1 路线和成长

H仍是五格：-2 / -1 / 0 / +1 / +2。路线由玩家选择：轻端使H向负方向积累，重端向正方向积累，两种星反应都积累所选方向。反应交替不再使H抵消。

自己的队伍角色在前台或后台触发有效星反应，且反应目标位于有效12米范围时，触发对应所选路线的猫主响应并移动H一格。两猫共享2.5秒响应间隔；一次攻击产生的多目标或多种反应合并为同一个输入事件，只按先结算的有效反应响应一次。间隔内的原生反应照常结算，不缓存补发猫响应。

每次达到新的本轮最高绝对H，获得一档成长，每档额外5%全队星反应伤害，最多10%。成长在本轮巡衡内保留：归衡或切路不会丢失；新巡衡开始时重新积累。

到达端点后H夹紧，同方向后续输入仍可触发猫响应，但不继续加档，不叠加旧版“稳定读数”个人伤害。

### 4.2 切路与归衡

切路时H直接归零并清除端点，不造成归衡伤害或发放校准窗口；保留本轮成长与已有校准窗口。两种反应都能重建新路线H。

校读或Q从非零H回零：到过端点为完整归衡，否则为普通归衡。归衡清除H与端点，但保留所选路线与本轮成长。归衡伤害、校准共享4秒间隔；间隔内H仍归零，不重复发奖。

- 普通归衡：150%攻击力普通冰伤，5米内柔和聚拢2秒。
- 完整归衡：190%攻击力普通冰伤，6.5米内轻端70%牵引；全队额外20%星反应增伤8秒，当前场上角色受到的削韧降低50%。窗口刷新，不叠层。
- 校读时H为0：只补发一次巡衡刻度，不产球、不重置自动刻度、不触发归衡。

校准在巡衡结束或倒下时立即结束，不留下孤立增益。基础40% + 本轮成长最多10% + 校准20%，零命角色自身星反应增伤上限70%；不含武器、套装、命座或队友。

### 4.3 控制

轻端：普莎主响应在5.5米内牵引1秒，中型敌人强度为小型25%；到端点后扩大至7米、1.5秒、中型40%。

重端：伊嘉主响应范围4.5米，较高伤害与高削韧。Boss和固定机关不被强制击倒；是否硬直由敌人韧性与免疫决定。控制比例为设计目标，尚无真实物理或敌人韧性验证。

## 5. 倍率、伤害类型与附着

### 5.1 E倍率（均为攻击力百分比）

| 来源 | 1级 | 6级 | 10级 | 13级 | 类型 |
| --- | --- | --- | --- | --- | --- |
| 启动 / 续开初始 | 68 | 86 | 101 | 114 | 普通冰伤 |
| 巡衡刻度 | 42 | 53 | 62 | 70 | 普通冰伤 |
| 轻端主响应 | 47 | 60 | 70 | 79 | 直接星反应冰伤 |
| 重端主响应 | 61 | 77 | 90 | 101 | 直接星反应冰伤 |
| 普通归衡 | 101 | 128 | 150 | 169 | 普通冰伤 |
| 完整归衡 | 128 | 162 | 190 | 214 | 普通冰伤 |

主响应的“星扩散 / 星超导”标签跟随触发该响应的实际反应，不由轻重路线决定。轻端也可造成直接星超导，重端也可造成直接星扩散；伤害元素始终为冰。此为娜蒂娅天赋的原创指定，不改变原生辉映。

### 5.2 附着职责

| 来源 | 冰附着 | 限制 |
| --- | --- | --- |
| E初始 / 普通及完整归衡 | 1U | 同一主动攻击组，每目标标准2.5秒 / 3次命中ICD |
| 巡衡刻度（含H=0校读补发） | 1U | 独立于主动攻击组，无额外ICD |
| Q初始 | 1U | 独立Q组，无额外ICD（受Q冷却限制） |
| 猫主响应 / 伴随响应 | 无 | 不附着，不产反应链，不写H；主响应首次命中可产1粒子 |

标准ICD中，时间重置与三次命中的计数独立维护；三次命中提前附着不推迟时间重置。同一目标同组共享，换目标分别计数。

猫伤害不是“反应被触发”事件，因此不能写H或再发动猫响应。娜蒂娅普通挂冰新触发的真实反应可正常输入H，仍受事件去重与2.5秒间隔限制。巡衡的独立附着补偿猫响应不再挂冰的职责调整，不能宣称与旧版挂冰量完全相同。

### 5.3 计算边界

普通冰伤与直接星反应分别汇总，不相加成可跨角色比较的总倍率。直接星反应采用对应原生公式：不得套用普通伤害的防御区、冰伤杯或战技 / 爆发普通增伤；元素精通、星反应增伤、基础提升、擢升、暴击与抗性按各自乘区处理。原生星扩散伤害、场地倍率、队友贡献须另建队伍模型，开发模拟器不伪造这些伤害。

## 6. 元素爆发｜三体归零·雪原校准

先将非零H归衡，再造成普通冰伤；巡衡存在时建立零点测区。无巡衡时只有初始伤害。

| 参数 | 规格 |
| --- | --- |
| 初始倍率1 / 6 / 10 / 13级 | 242 / 306 / 360 / 405%攻击力 |
| 能量 / 冷却 | 50 / 15秒 |
| 测区 | 至多12秒，实际min(12秒，当前巡衡剩余) |
| 伴随响应 | 当前主响应的55%，同一实际星反应标签，另一只猫表现 |
| 伴随控制 | 主响应35%，无附着、额外H或粒子 |

Q不补发刻度、不重排已排定刻度；下一刻度结算后才按所处状态选1.5秒或2秒间隔。测区按左闭右开处理，恰到终点的刻度按普通节拍结算，不跳过或顺延。续开E不延长已经建立的Q测区截止时间。

## 7. 固有天赋

### 外观不可作为量值

本轮最高绝对H每档提供5%团队星反应增伤，最多10%，见第4节。充能超过100%的部分，每1%提供0.25%娜蒂娅个人增伤，至多30%；分别明确作用于E/Q普通伤害与她的直接星反应伤害，并在各自增伤区加算。不是团队加成，不重复乘算。

### 误差本身也是记录

完整归衡打开8秒校准，提供20%全队星反应增伤和当前场上角色50%受到削韧降低。范围减抗已移至E本体，无需端点和归衡。

### 雪原札记

在至冬显示附近特产。风雪与极寒环境的非战斗移动体力消耗降低15%；靠近部分普通猫时不会立即使其逃跑。

## 9. 专武与构筑

### 零点不是答案

90级：542基础攻击、55.1%充能。施放E启动 / 续开后的20秒内，装备者在后台造成的普通伤害与星反应伤害分别提高24 / 30 / 36 / 42 / 48%（R1至R5）。校读与仅切路不刷新这个窗口。

该窗口内装备者在后台造成普通元素伤害或星反应伤害时，全队获得12 / 15 / 18 / 21 / 24%星反应增伤，持续8秒；刷新不叠层，前后台都受益，同名武器取最高。触发事件结算后发放，不倒推强化触发它的同一伤害。

### 套装与属性

- 炉心之证4件优先验证：装备者触发星反应或造成星反应伤害后12秒内，自身攻击+12%、队伍星反应增伤+50%；后台有效，同名不叠加。两件套攻击+18%。猫的直接伤害提供确定的启动来源。
- 队友已有炉心时，比较宗室等替代，不把重复炉心计作额外50%。宗室要求实际Q循环；黄金剧团只强化普通战技伤害部分，不作为直接星反应通用推荐。
- 沙：按是否需要每轮Q选择充能或攻击；杯优先比较攻击杯；头选双暴，西风优先暴击。双暴 / 攻击是满足所需循环后的优先项，精通作为可用词条另算。
- 冰伤杯仅强化普通冰伤部分，不再默认推荐。充能转伤不足以支持无限堆充能。

### 能量口径

不强制每轮Q的基础辅助没有通用充能硬门槛。需要每轮Q时，按实际前后台接球、队友粒子、敌人掉球、西风、直回与溢出逐时计算。

四人单人队示例：4个自产冰球前台接、1个后台接，基础能量为13.8；额外基础能量8 / 12 / 16时，C0支付50能量的理论需求为229.4% / 193.8% / 167.8%充能。只是输入假设，不是对应队伍的实测推荐；C4返还在Q支付之后，不能用于第一轮不足50时提前开Q。

## 10. 配队、循环与定位验收

轻端偏群怪：娜蒂娅 + 星扩散驱动 / 输出 + 另一个输出或功能位 + 生存位。重端偏单体：娜蒂娅 + 星超导输出 + 后台雷或功能位 + 生存位。混合风雷队任意反应均推动所选路线，无需控制元素顺序来避免H抵消。

基础循环：选路E → 切队友 → 任意两次有效星反应到端点 → 后台维持。约18至22秒续开即可，Q可省略。C1首次反应到端点。

主动循环：E → 两次有效输入 → Q完整归衡 → 队友输出；需要时再校读归衡。跳过一次归衡只损失额外窗口与对应伤害，不丢基础40%、本轮成长或30%减抗。

允许与奥黛塔同队，但不依赖她才能完成基础身份。同队时需计入失去的另一个队伍位置和重复套装；不把两个辅助的技能表简单相乘称为整队提升。

T0是设计目标，验收须统一投入、敌人、队伍和轮转，对比替换奥黛塔后的整队结果。至少覆盖星扩散群怪、星超导单体、已有其他减抗、混合队、换波、少一次归衡、不开Q与多轮能量；同时报告输出、增益覆盖、站场与生存位代价。

第一轮替换预算覆盖了上述主要情景的增益、路线减抗、站场和能量条件。归一化指数尚不能证明实战队伍 DPS 或 T0，且对减抗实际覆盖比例敏感。本轮因此冻结 C0 核心数值，等待完整轮转和实机数据再决定是否只动一个杠杆。

## 11. 数值验证边界与来源

简化比较只固定同一星反应伤害来源：原抗性10%、其他星反应增伤50%，奥黛塔60%增伤和14%基础增幅满额，无其他基础增幅。娜蒂娅不给基础增幅，以自身增伤和30%减抗参与比较。

| 娜蒂娅状态 | 无其他减抗，相对奥黛塔 | 已有40%其他减抗，相对奥黛塔 |
| --- | --- | --- |
| 成长完成，50%增伤 | 102.1% | 94.4% |
| 完整归衡窗口，70%增伤 | 112.3% | 103.9% |

不含双方个人伤害、启动、实际伤害时间分布、挂冰与场地贡献，不能视为整队DPS。未来角色与新反应不自动纳入未经核实的适配承诺。

## 12. 开发验收契约

开发工具为 `tools/nadia_skill_simulator.html`，核心 `tools/nadia_simulator_core.js`。只模拟原创状态、附着事件计数、伤害系数、覆盖和显式能量输入，不声称求解原生附着消耗或反应场地。反应事件是外部输入，必须标注。

- 前后台同等输入；事件去重；GCD内不吞原生反应；直接伤害不能写H。
- 两种反应交替仍能到端点；切路不发奖；归衡保留成长；续开重新成长；不叠巡衡。
- 22秒巡衡与18秒冷却；Q不重排刻度；精确边界不跳刻度；空目标跳过不产球。
- 敌人进入 / 离开范围即更新减抗；C6只一次冰减抗；无巡衡不留校准或测区。
- 普通冰 / 直接星扩散 / 直接星超导系数分列；C1 / C3 / C5倍率和C2 / C6乘区独立。
- 模拟器的E/Q 1、6、10、13级天赋表必须逐值对应第5、6节；常用C0/C3/C5场景仍按10/13级结算。
- 受到的削韧降低须用明确字段表示，不得误读为HP减伤；冰、风、雷减抗覆盖分别积分。
- 能量不足拒绝Q；Q支付50后C4返8；粒子接取位置、外部输入和能量溢出可追溯。
- 死亡 / 离队清空巡衡、测区、成长与校准；合作实例状态独立，同名队伍收益不叠加。
- HTML、玩家摘要、PDF和分享包同步；内部工具、原始私照和制作脚本不进分享包。

自动检查见 `tools/test_nadia_simulator.cjs`；内部情景预算见 `docs/nadia_team_budget_v3_1.md`。真实反应、整队 DPS 与交互手感仍须另行验证，不得写为已通过。
