## HTML 交互口径

- 每条台词显示完整文字、触发场景和播放控件；不自动播放。
- `preload="none"`，避免打开档案页时一次性加载全部音频。
- 文件缺失时保留台词文字，播放控件显示为不可用状态，不影响其他档案内容阅读。
- 最终审核需要逐条确认：发音、停顿、语气、文件与台词是否一一对应；网页资源完整性检查不能代替实际听感审核。
