# 《原神》原创角色完整设定｜至冬 · 娜蒂娅

> **母本。** 由 `genshin_character_full_design1.md` 与 `genshin_character_full_design2.md` 收束而成。那两份保留作草稿，冲突以本文为准。
>
> 设计目标：以真人与两只猫为视觉原型，做成能自然进入《原神》7.0 至冬时代的五星角色。不是写实复刻，而是「如果她生活在提瓦特，会成为怎样的可玩角色」。

---

## 0. 一句话概念

**一位温柔知性的至冬民间异常记录员，带着两只因旧时代锚定异常而分别变得「胖却极轻、瘦却极重」的真实家猫旅行；她以为自己一直在观察它们，最终才发现自己才是维持两者稳定的第三个锚点。**

她不是想把一切变回过去。她想弄明白：怎样才能让已经改变的一切，继续稳定地走向未来。

## 2. 原型转化原则

### 2.1 人物｜`girl.jpg`

采用「熟悉她的人能够认出原型，陌生人会认为这是完整原创角色」的改编尺度。

**必须保留**

- 柔和偏椭圆的脸型；
- 过肩深色轻波浪（不要齐肩死直，也不要垂到腰）；
- 细金属框、圆形略偏椭圆的眼镜；
- 笑起来明快、亲和，没有攻击性；
- 162 cm 纤细成年女性比例与气质，不做幼态少女，也不做高冷御姐。

**正立绘表情**

轻微侧头，眼和嘴角带自然笑意，**几乎不露齿**。看起来像刚刚发现一个有趣的新数据，而不是准备毁灭世界。

闲置、表情包、部分语音立绘再给更接近照片的明快笑。

**明确不采用**

- 真猫耳、猫尾、猫娘口癖；
- 照片中的活动装、深领口、袖口大褶边、智能手表；
- 半透明黑丝；
- 眼镜链（脸、眼镜与双环发夹已经足够）。

衣服按至冬野外记录员设计，**不映射真人原图服装**。

### 2.2 两只猫｜`xiting/`

外形以照片为准。文档只规定「胖轻 / 瘦重」的战斗象征与配件差异。

| 文件                    | 用途                             |
| ----------------------- | -------------------------------- |
| `fat.jpg`               | 轻相普莎的体型、毛色、眼神       |
| `thin1.jpg` `thin2.jpg` | 重相伊嘉的体型、毛色、眼神       |
| `two.jpg`               | 两人并置时的体型对比与立绘对角线 |

两只猫都是真实家猫，不是元素生命、使魔、召唤物或机械仿生体。

## 3. 性格

### 核心气质

**温柔知性 + 一点天然呆。**

不是天才型傲慢学者，也不是活泼少女型研究员。面对最违反常识的事情，第一反应通常不是惊叫，而是把眼镜推回去，再测一次。

### 对陌生人

- 很有礼貌，说话有条理；
- 不轻易下结论；
- 不知道的事情会直接说「这个我还没有证据」。

### 对两只猫

专业性会明显松动。

她会一边做异常测量，一边给猫梳毛；会在严谨记录里写「它今天不配合」；抱伊嘉前会先调整站姿；普莎被风吹起来时，她可以不中断说话就把它捞回来。

她从来不用「实验品」称呼它们。正式报告里写的是：

> **「同行个体 A」** 与 **「同行个体 B」**

私人笔记上其实写着：普莎、伊嘉。

### 人格矛盾

她擅长研究「什么是正常」，故事最终迫使她面对：

> **如果两只猫已经适应了现在的自己，那么把它们恢复成从前的样子，究竟是为了它们，还是为了自己的安心？**

## 4. 外观设计

### 4.1 总体方向

**至冬野外调查员 × 温柔学者。**

远看可靠、成熟、适合雪原；近看柔软、精细、带生活感。

不是礼服，不是军装，不是猫娘，也不是满身齿轮的机械工程师。不要做成典型蓝白冰系角色：黑发、暖色内层和深色外衣共同提供视觉重心。

### 4.2 配色

**外层：** 深灰蓝、石墨蓝、极少量近黑。用于披肩、外套、腰封、靴子、工具。

**内层：** 奶白、暖灰、很浅的冰蓝。用于高领内搭、裙摆内侧、靠近脸部的区域。

**点缀：** 银色金属、少量香槟金、Stellar Linchpin 的冷蓝光。

### 4.3 发型与头饰

过肩深色轻波浪。主体自然垂落，发尾轻微内收，一侧有稍长的侧发，刘海轻度不对称。

脑后藏一根极细的冰蓝色束带，远看几乎看不见。

头部唯一明显装饰：**双环测量夹**。两个略微错开的圆环，一边悬着极轻的银白羽片，一边悬着小型深色金属坠。分别暗示轻 / 重。人物身上只保留这一处轻重要符号，腰带不再挂空心坠与实心坠。

### 4.4 眼镜

细金属框，暖银灰，圆形略偏椭圆。镜腿很细，不产生遮挡眼睛的大面积反光。

这是识别点，不为了「五星感」去掉。无眼镜链。

战斗中偶尔会推一下眼镜再开始测量，但不做成夸张的学者刻板动作。重击后眼镜会真的滑一点——是法器冲击，不是摆造型。

### 4.5 服装结构

**上身**

不对称雪原调查短披肩：右侧覆盖更多肩背，左侧稍短，方便持笔、翻记录册、操作法器。边缘不是厚重大毛领，而是较细的冬季织物与浅色绒滚边。单侧时尚大毛领会太像舞台或猎装，和 Odette 的华丽冬装抢语言。

内部：奶白色高领保暖内层 + 修身深灰蓝调查服。胸腹不裸露。袖口干净利落，可有小型金属扣，不要宫廷褶边。

整体强调：**成年、知性、实用。**

**腰部**

职业信息最集中的区域：

- 小型防水记录册；
- 折叠尺；
- 样本瓶；
- 笔；
- 猫零食袋；
- 小型测量仪；
- Stellar Linchpin 固定框。

容易被玩家发现的生活细节：

> **实验样本袋和猫零食袋用了几乎相同的收纳袋。** 她拿错过很多次。

**下装**

短至中长度的不对称裙摆 + 功能型内层。

腿部使用 **不透明、哑光的深石板蓝保暖打底**，无透肤、无蕾丝、无丝袜高光。膝部与小腿可有非常淡的刻度线 / 经纬测量纹样，远距离不抢视觉。

她长期在至冬雪原工作。半透明黑丝既泛化，也削弱野外可信度。

**鞋**

深灰蓝中筒调查靴。防滑底、金属扣、冰面固定结构、极细的淡金属刻度装饰。不是高跟鞋；鞋跟只保留轻微高度，用于轮廓。

### 4.6 Stellar Linchpin

位于 **左腰稍后**。

不是简单挂在腰上的圆形饰品，外面被她自己做的 **三层可转动测量环** 包围。静止时三环略微错位。使用能力时，三环先自行校正到同一轴线，再亮起冰蓝色 Stellar 光。

每次进入真正的轻 / 重异常状态时：

> 指针都会超过正常刻度范围。

这是重要视觉伏笔：**她的仪器从来没有真正测量出三人的极限。** 披肩左侧较短，正好让这组环在战斗中可见。

## 5. 两只猫

它们真的只是娜蒂娅养大的两只普通家猫。至少，曾经是。

名字按事故前的外观来起，所以「看起来沉的其实轻」才能成立。正式档案仍可写同行个体 A / B。

### 5.1 普莎｜轻相

**Пуша / Pusha**，绒毛。

外形（`fat.jpg` / `two.jpg` 左侧）：

- 圆脸、圆润体量，奶油金 / 浅金被毛；
- 胸腹与爪子偏白；
- 琥珀金圆眼；
- 神情经常有一种若无其事的镇定。

异常：

体积没有变小，质量却明显不相称。不是「比较轻」，而是一阵足够强的雪原风真的可能让它离开地面。跳起后落地慢得不像猫。人轻轻一抱像抱起一团厚毛毯。

旅行装备里长期有一根很细的安全牵引绳。不是为了防逃，是为了防止它 **被风带走**。

**配件（仅这一只保留锁的剪影）：**

至冬银 / 冰蓝的长命锁。保留照片里锁的轮廓与护身意味，去掉红绳与金色璃月感。空心锁与真实质量形成反讽：看起来像坠子，坠不住它。

战斗对应：

> **轻相 / 浮量 / 牵引 / Stellar Swirl**

### 5.2 伊嘉｜重相

**Игла / Igla** 的中文柔化，针。

外形（`thin1.jpg` `thin2.jpg` / `two.jpg` 右侧）：

- 修长，象牙 / 乳白；
- 耳鼻尾只有极淡的奶茶 / 浅橘点；
- 脸更窄，耳更尖；
- 冰蓝眼；
- 走路和普通猫没有区别，动作看起来非常轻巧。

异常：

体积仍是普通猫，有效质量却远超外观。薄冰会细裂，木板会微微下陷，雪地脚印异常深。看起来一只手就能抱起，实际上必须认真发力。它自己完全适应，行动并不迟钝。

娜蒂娅第一次在事故后重新抱起它时，差点把手里的记录册扔出去。之后在笔记第一页写下：

> **「第一原则：禁止通过外观预测质量。」**

**配件（不要锁）：**

短而结实的炭灰蓝项圈，扣具加厚，下面一颗看起来普通的哑光冰石。普通猫铃会被它扯坏，所以这条项圈看起来更素，实际是按「更重的同行者」做的。

战斗对应：

> **重相 / 坠量 / 压制 / Stellar-Conduct**

## 6. 五星专武｜「零点之外」

类型：**五星法器**

外观看起来不是传统魔法书，而是：

> **一本能够自行翻页的野外调查记录册，与两组悬浮测量环组成的组合式法器。**

书页灰白，边缘有冰蓝元素纹。金属环令人想起天平、测角仪、星盘、游标，但不直接复刻现实仪器。

攻击时：环展开，页面自行翻动，刻度在空气中形成冰晶坐标。她更像在校准装置，而不是挥舞武器。

定位偏：**元素充能 / 后台辅助 / Stellar 反应支持。**

武器故事最后一句：

> **「零点不是答案，只是决定从哪里开始记录。」**

故事中可写一座被雪盖住的小院、一次未完成的庭院测量，把「庭」留在文本里，不写进武器名。

## 7. 战斗定位

**五星 Cryo 后台辅助 / 控场 / 双路线状态管理。**

7.0 现行生态里，Odette 已是冰元素 Stellar Linchpin 五星辅助：启用 Stellar-Conduct / Stellar Swirl、后台造成 Stellar Glimmer 伤害、持续挂冰、直接强化 Stellar Glimmer 伤害。

娜蒂娅 **不做成另一个 Odette**。两人抢同一后台冰位，是 **同槽侧路**：

- 要直接、稳定的 Stellar 输出增强 → Odette 更简单；
- 要双路线战场控制、聚怪 / 压制、轻重状态管理 → 选娜蒂娅。

四命可以给短窗 Stellar 反应强化，但主价值必须落在 **控制战场如何发生反应**，而不是最高数字。

普通玩家：放战技即可获得稳定挂冰、控场与路线辅助。  
高阶玩家：才需要理解衡标，并主动让系统失衡再带回来。

不要求频繁看复杂 UI。Boss 不会被强制击倒。

## 8. 核心机制｜「衡标」

隐藏在两只猫行为中的质量状态：

```text
轻端 ←────── 归衡 ──────→ 重端
 -2    -1      0      +1    +2
```

释放元素战技以后，两只猫自动协作。普通玩家不需要看见这张表。

高阶玩家会发现：

- **Stellar Swirl**（风 + 冰）让衡标向 **轻端** 移动；
- **Stellar-Conduct**（冰 + 雷，需队伍中有 Stellar Linchpin）让衡标向 **重端** 移动。

于是可以主动控制轻相 / 重相 / 归衡。

高阶振荡玩法需要风与雷都在队里。这正是 7.0 Stellar 双路线队的结构，也是她相对 Odette 的操作上限来源。

## 9. 普通攻击｜「霜度测录」

操纵测量环与冰晶刻度，最多四段远程冰元素攻击。动作不是传统法师大幅挥手，而像：标点 → 记录 → 校正 → 结论。

1. 一道细小冰晶刻度向前展开；
2. 两道弧形测量环交错；
3. 在空中轻轻写下一笔，冰晶从标记位置产生；
4. 合拢记录册，此前三个测量标记同时碎裂，造成冰元素伤害。

### 重击｜「零点校读」

短暂展开圆形测定区域。冰晶刻度向中心收束，造成范围冰元素伤害。结束后她会自然扶一下眼镜。

### 下落攻击

借助法器先减缓下坠，再突然解除这次「轻相」，以冰元素冲击地面。

## 10. 元素战技｜「双相巡衡」

轻点记录册：

> **「普莎，伊嘉——开始记录。」**

两只猫进入战场，跟随当前场上角色调查。

### 普莎｜「浮量响应」

队伍触发 **Stellar Swirl** 时，普莎轻轻跃起。由于质量异常低，它实际上不是「跳」，而是慢慢漂高了一点。随后产生短暂轻相区域。

效果方向：

- 对周围敌人产生柔和牵引；
- 小型敌人更容易被聚集；
- 中大型敌人的移动受到一定限制；
- 造成一次冰元素协同伤害；
- 衡标向 **轻端** 移动。

连续触发轻相后进入 **「轻端观测」**：牵引范围与控制稳定性增强。玩法偏 **Stellar Swirl / 聚怪 / 多目标**。

视觉：冰晶向上飘，雪粒反常上升，碎屑有失重感。

### 伊嘉｜「坠量响应」

队伍触发 **Stellar-Conduct** 时，伊嘉像普通猫一样轻巧跃起，然后落地。画面却出现完全不符合体型的低沉冰裂与质量冲击，形成短暂重相区域。

效果方向：

- 一次压制型范围冰元素协同攻击；
- 降低敌人移动能力；
- 提高大型目标受到连续 Stellar 攻击时的稳定控场；
- 衡标向 **重端** 移动。

连续触发重相后进入 **「重端观测」**：压制与单目标辅助进一步提高。玩法偏 **Stellar-Conduct / 精英 / Boss**。

Boss 不强制击倒，避免破坏现有战斗逻辑。小怪可以表现短暂的「微浮升 → 重压回落」；这不是大招默认硬控循环。

## 11. 高阶机制｜「归衡」

假设当前重相 +2，再通过 Stellar Swirl 把衡标拉回来：

```text
+2 → +1 → 0
```

衡标重新穿过 **0** 时，两只猫同时触发 **「归衡响应」**：

普莎从上方缓缓下降，伊嘉从下方跃起。一轻一重的冰晶轨迹在同一位置交汇。

产生：

- 一次较强的范围协同攻击；
- 短暂同时获得轻相与重相的部分功能；
- 为队伍提供一个短时间 Stellar 反应强化窗口。

真正高阶玩法不是永远停在某一边，而是：

> **主动让系统失衡，再把它带回来。**

这非常符合记录者的人设。

## 12. 元素爆发｜「三体归零·雪原校准」

打开记录册。镜头进入短暂五星爆发动画。

普莎落在左侧测量盘，测量盘猛然 **上升**。  
伊嘉跳上右侧，整个右侧 **直接下沉**。  
指针猛烈左右摆动。

她安静看了一眼读数，轻轻推眼镜：

> **「误差确认。」**

手指放在中央刻度上。画面中出现第三个点——她自己。三点锁成巨大的冰蓝色三角测量结构。轻与重不再互相抵消，而是在她的控制下进入动态平衡。

> **「那么——重新归零。」**

巨大冰蓝测量环覆盖战场。衡标返回中央。形成 **「零点测区」**。

### 零点测区

持续期间两只猫都更活跃。无论队伍触发 Stellar Swirl 还是 Stellar-Conduct，另一只猫都会产生一次弱化版伴随响应：

- Swirl：普莎主响应 + 伊嘉辅助压制；
- Conduct：伊嘉主响应 + 普莎辅助聚拢。

真正实现 **轻中有重，重中有轻**，并提高战场稳定性。

爆发不是全屏核爆。视觉重点是：两个完全不符合体型的质量现象，与她在中央保持绝对冷静。大招结束时两只猫回到她附近。她低头看仪器：数值仍然不完全守恒。短暂皱眉，战斗继续。

## 13. 固有天赋

### 「外观不可作为量值」

双相巡衡存在期间，若连续触发同一种 Stellar 反应，对应猫的响应会逐步增强。

即使完全不研究归衡，角色也能稳定发挥。这是 **低操作门槛**。

### 「误差本身也是记录」

衡标从轻端或重端重新返回归衡位置时，「归衡响应」获得额外强化。

这是 **高操作上限**。普通玩家不用管。研究机制的玩家可以构筑 Swirl → Conduct → Swirl，或反过来。

设计含义：她不再试图消除所有误差，而是学会利用偏差本身。

### 探索天赋｜「雪原札记」

在至冬探索时，显示附近部分区域特产的位置；在极寒、风雪类环境中的部分移动体验得到轻微改善。

设定解释不是魔法。她把风向、积雪、坡度、地面承载情况都记过。

风味效果：靠近部分普通猫时，它们不会立即逃跑。

## 14. 命之座

命座定义玩法方向，不伪造精确倍率。

### 第一命｜「第一条：不要相信眼睛」

释放双相巡衡后，衡标首次发生变化时额外获得一次对应响应。让普通玩家更快进入轻端或重端。

### 第二命｜「第二条：重新称量」

轻端与重端的效果进一步强化。部分原本难以受到控场影响的敌人，也能获得弱化版轻相牵引 / 重相迟滞。明显改善实战体验。

### 第三命｜「第三条：记录直到一致」

元素战技等级提高 3 级。

### 第四命｜「第四条：误差从不是零」

触发归衡响应后，全队获得短时间 Stellar 反应强化。把高阶玩法转化为队伍收益，但强度应低于 Odette 的主增伤轴。

### 第五命｜「第五条：零点只是起点」

元素爆发等级提高 3 级。

### 第六命｜「最后一条：我们三个都在这里」

零点测区持续期间，每次触发 Stellar Swirl 或 Stellar-Conduct，普莎与伊嘉都以完整效果进行一次协同响应。衡标不会被锁在某个端点。

高命由「管理天平」变成「主动让两端不断碰撞」。视觉上两只猫几乎一直围绕角色战斗。

第六命名称同时也是剧情的情感结论。

- 高阶状态管理。

## 16. 世界观与人物弧线

### 第一层｜生活

数年前，娜蒂娅还是普通的民间生态与异常记录员。不隶属愚人众，也不是在职官方科研机构成员。依靠地方委托、学者间的信息交换与私人经费，在至冬各地记录：地脉异常、不正常的冰层、生物迁徙、被遗弃的旧装置、口耳相传却没有正式档案的怪异现象。

家境普通，没有显赫家族，没有军方背景。年轻时受过基础测绘和自然现象记录训练，但相比坐在研究室里，她更喜欢亲自去看。别人问她为什么很多报告只能写「原因未知」，她说：

> **「不知道原因，也是一种结果。」**

一开始只想回答「它们到底发生了什么」，后来变成「这种状态会不会伤害它们」，最后变成「如果它们并不需要变回去，我是不是应该接受这一点」。这是最重要的情感核心。

### 第二层｜旧设施

一次调查中，她带着两只猫进入地图上只标成「旧地质观测区」的地方。为了躲避暴风雪，走进一处未标记的地下结构。看起来像很久以前被废弃的研究设施。她并没有深入，只是找安全区。

设施下方还藏着更古老的结构。某个沉寂多年的系统因为三人进入而重新启动。没有爆炸，没有怪物，没有明显攻击。只有短暂的 **完全安静**：雪声消失，风声消失，仪器全部归零。三人失去意识。

醒来后猫仍在。几天后称重，普莎数据异常低，换三台秤都一样；伊嘉直接超过量程。这才是她进入「异常质量研究」的开始。

多年后她找到损坏的旧记录。当年的设施不是异常的源头，只是一个 **研究站**。过去的至冬研究人员在更古老的地下遗迹中，发现一种难以解释的现象：

> **某种锚定关系，可以让本应属于一个整体的属性，在多个对象之间重新分配。**

质量只是其中最容易观察到的表现。旧研究人员试图控制它。项目失败，设施关闭，记录被分散、封存或删除。

娜蒂娅与两只猫只是多年后误入残留区域的普通生命。不是实验对象，更不是隐藏了十年的世界核心人物。

来源不揭穿。不要新造一套宇宙学，也不要直接点名第三降临者或 Hyperborea。纹理可以像封存几何、失败的测量、被拆散的档案。

### 第三层｜异常重新开始

几年里，两只猫的状态几乎完全稳定。它们吃饭、睡觉、打闹、抢位置。普莎学会从高处非常缓慢地落下；伊嘉发现没有什么能轻易把它从喜欢的位置抱走。娜蒂娅慢慢停止使用「恢复」，改成「稳定」。

直到最近。测量曲线再次变化：普莎越来越轻，伊嘉越来越重，速度开始增加。更糟的是，过去两者之间近似存在的平衡对不上了。

**逻辑必须写明：** 若她一直是第三锚点，两只猫之间本来就不该自成封闭守恒。早年看起来「对得上」，是因为她自己的 Linchpin 长期稳定，系统被她这个锚点兜住。近年失稳，是因为 7.0 正在发生的事——暴风雪加剧、旧系统被环境重新搅动——使这个锚点开始不够用。不是因为她某天突然发现「样本数填错了」才开始坏。

「样本数填错了」是她理解自己位置时的性格反应，不是物理原因。

这也是她进入当前至冬区域剧情的原因。

### 第三锚点

她过去最大的错误，是一直把对象记成「2」。实际上是「3」。

```text
普莎  → 质量向外偏移（轻相）
        \
         娜蒂娅 → 两者之间的稳定锚点
        /
伊嘉  → 质量向内偏移（重相）
```

她显现出的 Cryo Stellar Linchpin 不是后来偶然获得的新力量，与当年的事件是同一套系统的第三部分。危机中昏迷后显现力量，符合提瓦特既有的「之后发现自己能使用元素」叙事。她是个案，不是圣遗物说明书。

她盯着图表看了几分钟，把眼镜推回去，划掉标题「双体异常长期观测记录」，写成：

> **「三体异常长期观测记录」**

旁边补一行：

> **「此前样本数量统计错误。」**

不是崩溃，也不是突然怀疑人生。这就是她。

## 17. 主线定位

**至冬某一重要区域篇章的关键调查伙伴，而非世界中心。**

旅行者第一次见到她，不是在重大阴谋现场，而是在雪原。有人正在追一只飘在半空中的胖猫。派蒙大概会先说：「猫……为什么在飞？！」她一边追一边回答：「严格来说不是飞，是下降速度过低——普莎，不要往那边！」

玩家最初只觉得有趣，之后才发现她调查的东西与当前区域异常有关。

旅行者负责进入真正危险的地方。她负责判断看到的东西究竟意味着什么：重要证人、异常机制解释者、可信赖的区域伙伴。她不会决定至冬的最终命运。

剧情结束后，她仍有自己的研究、生活和两只猫。她是生活在提瓦特的人，不是为了主线而出生的装置。

人间对手：**已解散的旧科学院 / 旧宫廷项目余绪** 在重新搜集封存记录与残留装置。不点名愚人众，避免和 7.x 后续官方内斗撞车。

## 18. 传说任务

### 「双衡之章·第一幕」

**对外标题：** 《比雪更轻，比承诺更重》  
**任务日志标题：** 「猫、砝码与第三个数字」

表面任务：帮她重新调查旧设施，寻找稳定两只猫的方法。开场可以很轻松——普莎被暴风送到屋顶上，玩家先当趣味委托，再发现一只不该这么轻，另一只不该这么重。

中段：设施正在再次运行。找到大量被人为拆分的记录。旧项目内容与她多年的私人记录高度吻合。旧科学院余绪也在挖同一批档案。

高潮：两只猫的状态突然失衡。系统试图「重新校准」，理论上可以让三者回到事故以前，但没有人能证明现在的普莎和伊嘉还能不能保持如今的状态。她必须承认自己是第三锚点，而不是旁观者。

她拒绝强制复原。选择利用自己的 Stellar Linchpin **稳定现在的三者**。

结尾：危机暂时稳定。她没有获得「治好它们」的答案。古代设施的真正来源仍然不揭开，只解决她们三个自己的问题，同时给至冬更深的世界观留入口。

旅行者问接下来怎么办。她看着两只正在互相抢位置的猫：

> 「继续测量。」

停顿一下。

> 「还有……继续养。」

## 20. 待机动画

### 待机一｜「再次测量」

拿出小型便携秤。普莎跳上去，指针几乎不动。她记下一行。伊嘉随后走上去，秤直接压到底。她沉默，把刚才写的数字划掉，重新校准设备。

### 待机二｜「风」

一阵风吹过。普莎慢慢离开地面。她甚至可以不停止看笔记，伸出另一只手抓住锁或安全带，平静拉回来。这时伊嘉也想跳进怀里。她看见以后立刻双脚站稳，然后才伸手。

### 待机三｜「猫毛」

翻开记录册，发现里面夹了一根猫毛。捏出来，看一眼，吹掉。再次翻页，又一根。停顿两秒：「……算了。」继续写。

### 待机四｜「抱错了」

伊嘉走到脚边。她自然弯腰准备单手抱起来。停顿，表情微微一僵，换成双手，仍然很重。沉默两秒，推眼镜，在本子上记：「今天也是稳定状态。」伊嘉若无其事地看着她。

## 23. 立绘与 Splash Art

### 构图｜「双向失衡」

娜蒂娅站在中央，身体略微侧转。一手扶打开的记录册或圆框眼镜，另一手控制悬浮测量环。面带轻微笑意，黑发被雪原风轻轻带起。不做战斗怒容。

**左上：** 普莎缓缓漂浮，四爪微张，表情无辜；雪粒逆向升，冰晶轨迹向上。  
**右下：** 伊嘉落在冰面上，身体仍修长轻盈，触地点出现细密冰裂；蓝眼形成焦点。

```text
普莎 ↗

      娜蒂娅

             ↘ 伊嘉
```

她位于轻与重之间。背后是巨大半透明双环测量结构，中央指针停在零点附近，却并未真正与刻度重合。背景可以有至冬雪原、被雪埋住的旧设施轮廓、极淡的三点锚定几何，不要让特效淹没人物。

### Splash 优先级

1. **她本人**：脸、眼镜、黑发必须先被看见；
2. **两只猫**：一眼理解一只向上、一只向下；
3. **轻重异常**：不依赖文字；
4. **冰元素 Stellar Linchpin**；
5. 最后才是冰晶、测量环、雪花。

不能让大量蓝色特效淹没人物。猫保持真实家猫体型；靠构图与运动差保证可读，不要把它们画成元素精灵。

## 25. 玩家印象曲线

第一次看到：

> **「哦，一个戴圆框眼镜、带两只猫的至冬记录员。」**

玩十分钟：

> **「等等，为什么胖的那只会飘？」**

玩一段时间：

> **「原来技能真的在算轻重状态。」**

做完传说任务：

> **「她研究的从来不只是猫。」**

最后记住的不是阴谋，而是：

> **一个很温柔的人，认真地试图让两个已经发生改变的小生命继续好好生活。**

---

## 26. 核心一句话

> **娜蒂娅不是想把一切重新变回过去。**  
> **她想弄明白，怎样才能让已经改变的一切继续稳定地走向未来。**

本文可直接作为后续五星立绘生图、三视图和技能概念图的母设定。猫名已定；卡面名、称号、战斗与剧情口径以本文为准。
